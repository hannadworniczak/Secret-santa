# Chrismas Secret Santa

A one-page website for our Secret Santa. Open it, type your name, pick a gift box, and see who you're buying for.

- `index.html`: the whole website, including the sealed draw. This is the only file the site needs.
- `template.html` + `draw.py`: only for making a brand-new draw (`python draw.py` rewrites `index.html` with new random pairs). Running it changes everyone's matches.

Rules of the draw: nobody draws themselves, Hanna and Maja can't draw each other, and everyone gives and gets exactly one gift.
